a design system for pages

Design tokens, CSS and about 7 KB (gzipped) of vanilla JS. Eight themes, each with a dark and a light mode. No framework.

principles

In priority order. If two conflict, the earlier one wins.

01
type

Thin, lowercase and large. One easing curve for all motion.

02
lines

Hairlines and grids give the structure. Tiles and raised surfaces are the only filled shapes.

03
Jaipur

A jaali lattice, an Amer arch, a blue-pottery rosette and one rose accent. Used sparingly, except the lattice.

install

Link two stylesheets and add one class.

# install
npm install jaali

<!-- html -->
<link rel="stylesheet" href="jaali/fonts.css">
<link rel="stylesheet" href="jaali/jaali.css">
<body class="jaali">
  <h1 class="j-title">hello</h1>
</body>

// optional behaviour
import { mount, jaaliField } from 'jaali';
mount();
jaaliField(document.querySelector('canvas'));
